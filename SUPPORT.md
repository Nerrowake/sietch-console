# Support

Sietch Console support is focused on reproducible installation, setup,
server-management, and desktop application issues.

## Before Asking

- Read `INSTALL.md`.
- Review `docs/user-setup-guide.md`.
- Check `docs/troubleshooting.md`.
- Confirm Windows edition and Hyper-V availability.
- Check Sietch Console app logs.

## Useful Details

Include:

- Sietch Console version
- Windows version and edition
- whether Hyper-V is enabled
- setup wizard step or view affected
- relevant app logs with secrets removed
- whether the issue affects local, remote, or cloud-sync features

## Security

Do not include tokens, cloud credentials, WMI credentials, remote management
bearer tokens, private server IPs, or player personal data in public issues.
